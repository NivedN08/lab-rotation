# P2 Workspace

You are the **P2 Workspace** session for **Lab Rotation**, our entry in today's
Multiplayer AI Hackathon (Finch, AWS Builder Loft, Mon Nov 23 2026). We submit by
**5:50 PM**. Nick (nick-devvv) supervises you; work without asking to continue.

**The product.** A flight simulator for an analyst's first weeks. A panel of AI
scientists (Dr. Vale the lab head, Ines the examiner, Sam the methods reviewer,
Telem the librarian, Riley the careless AI intern) hands the learner a small retail
dataset (customers, loyalty members, visits, spend, stores, regions; up to 3 tables,
a few hundred rows) and a claim to check. The data may hide one planted trap
(duplicated transactions, one region's spend in cents, a loyalty flag coded
backwards in the dictionary, a point-of-sale confounder, a hidden variable in a
second table) or none (a clean twin). The learner explores with a read-only SQL box,
profiles and charts, cites evidence, answers. The panel confers in a BAND room,
Ines shows the failing Bruin check, the verdict quotes the learner's own words, the
grade is sealed in a hash chain, a learner model (BKT + bandit) picks the next task.
The 2D lab floor (and a three.js view) shows agents walking, envelopes flying,
and a lab log with every event's reason.

## Your job
You build the learner's analyst workspace (`web/src/workspace/`).

- **Table browser**: the task's tables from `GET /api/sessions/{id}/task` and rows
  from `/tables/{table}`, paged, column docs from the dictionary on hover.
- **SQL box**: `POST /api/sessions/{id}/query`; show columns/rows, row count, time,
  truncation and errors plainly. History of queries by id (q1, q2...), click to
  rerun. Read-only: the server enforces it.
- **Column profiles**: `/tables/{table}/profile`; nulls, distinct, min/max/mean, a
  small histogram or top values.
- **Chart builder** (recharts): pick a query result, x, y, group; bar/line/scatter.
- **Evidence picker**: cite rows, columns, cells or queries (refs in
  `contract/events.md`); `POST /evidence`; show the cited list.
- **Answer form**: verdict (holds / fails / can't be judged), trap (the five plus
  "none"), the learner's own words, the cited evidence; `POST /answer`. Voice input
  with the browser's Web Speech API (fallback: typing).
- **Timer** for judge mode (240 s from `session.start`).
- Export a `<Workspace session={...} />` (and pieces) that P3 mounts; types from
  `web/src/data/contract.ts` (P3 owns it; ask in `requests/p2.md` for changes).
- Until N1's mock server is up (target 12:45), stub the API with
  `web/public/mock/task.json` and fake rows. Then run against `LAB_MOCK=1`.

Gate: `cd web && npm run build` passes.
