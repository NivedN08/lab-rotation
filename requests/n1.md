# Requests from N1 (session engine)

The engine calls these through `lab/session/sources.py`, which falls back to a built-in
stub when a module is missing or raises, so nothing here blocks a merge. Shapes below
are what the adapter reads; extra fields are fine.

## N3: `lab/tasks/bank.py`

- `pick(skill, tier, seen) -> bank_id` (`skill` is a trap id, `seen` a list of bank ids).
- `load(bank_id) -> dict` (or an object with the same attributes):
  - `public`: the task in the exact shape of `contract/mock_task/task.json` (any `id`; the
    engine replaces it with the slot id `t1`/`t2`/`t3`).
  - `dir` (or `public_dir`): folder with `tables.json` and the CSVs (what
    `lab.workspace_sql` reads).
  - `key`: `{trap, verdict, careful: {verdict, trap, note}, careless: {verdict, trap,
    note}, columns: [column names that matter], hints: [three hint lines, gentlest
    first, never naming the trap], checks: [check ids]}`. `columns` decides which
    learner queries count as useful (struggle meter) and which evidence counts.
- `list_ids()` (optional): every bank id, for tests.

## N3: checks and learner model

- `lab.tasks.checks.run(bank_id) -> [check.result data]` (`{check, trap, passed, detail,
  rows?, bruinRun?}`), or tell me the function name you prefer.
- `lab.learner.update(learner, trap, correct) -> {trap, from, to, attempts}`,
  `lab.learner.mastery(learner) -> {traps: [{trap, score, attempts}]}`,
  `lab.learner.pick_next(learner, seen, tier) -> {skill, tier, reason, fallback, bandit?}`.

## N2: sponsor clients

- `lab.sponsors.band.BandRoom(on_call=...)`: using `.post(agent, text, mentions)`,
  `.relay_appeal(text)`, `.health()` and `band.configured()` as on your branch. Thanks.
- `lab.sponsors.telem.search(query, on_call=None) -> {query, results: [{title, url,
  snippet}], trace, cached}`.
- `lab.sponsors.runware.tts(agent, text, on_call=None) -> {file, seconds, cost}` with the
  mp3 saved in `data/audio/` (`file` is the bare file name).
- `lab.sponsors.runware.riley(prompt, on_call=None) -> {text, model}` (optional; the
  engine falls back to `claude -p`).

## P3 / P2: contract additions (optional, nothing breaks)

- `GET /api/session/:id/tables`, `.../rows` and `.../profile` take an optional
  `?task=t1` so a replay can show the workspace of any task of a finished session.
  Without it they use the current task (or the last one when the session is over).
- `GET /api/agents` items also carry `title` ("Lab head", "Examiner", ...).
- Portraits, when N2 has made them, are served at `/api/portraits/<file>`.
- `POST /api/session/start` accepts `{"mock": true}` to get a mock replay session from a
  live server; session ids starting `mock-` are mock replays.
