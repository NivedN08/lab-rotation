# Requests from N3 (Data and learning)

## Lead: add `logs/queries` to `.gitignore`

`bruin query` appends a `logs/queries` line to the repo's `.gitignore` whenever that line is
missing, so the main checkout shows a `.gitignore` change after any query. Nothing new gets
tracked, because `logs/` is already ignored. Committing the line once stops it.
`bruin/demo.sh` puts `.gitignore` back as it found it in the meantime.
